Milestone Outputs in Production

M1 - VOTING

Voting Integration

On-chain voting through Begin's dApp Store rating system. Every vote is recorded on Cardano mainnet under metadata label 1668, registered in CIP-10.

  • User registration for voting
  • Voting on items, recorded on-chain
  • Voting results display
Live
M2 - BIOMETRICS

Biometric Seedphrase

Face capture in reference to ISO/IEC 19794-5, seedphrase derived from face descriptors by multi-capture consensus, passwordless login and transaction authorization.

  • Biometric enrollment
  • Seedphrase generation
  • Passwordless login
  • Transaction authorization
Live
M3 - WOOCOMMERCE

Payment Module for WooCommerce

BeginPay gateway: ADA at checkout, live fiat-to-ADA rate, QR code with merchant address and exact amount, on-chain verification via Blockfrost. Originally planned as Shopify; moved to WooCommerce after Shopify closed external payment integrations.

  • Select ADA at checkout
  • Exchange rate (USD / EUR to ADA)
  • QR code generation
  • Payment shown in checkout
Done · Beta test store
M4 - BITCOIN

Bitcoin Compatibility

Bitcoin account under the same seed as Cardano, SegWit (p2wpkh) and Taproot (p2tr) addresses, live fee estimation, signing and broadcast on Bitcoin mainnet.

  • Transaction creation with live fee
  • Transaction signing
  • Transaction broadcasting
Live

Final Close-out

Challenge KPIs

  • Bring real Cardano use cases into an everyday wallet: governance-style voting, payments at online shops, and multi-chain holdings.
  • Lower the barrier to self-custody with passwordless, biometric access instead of a written seedphrase.

Project KPIs

  • Four modules delivered: Voting, Biometric Seedphrase and Bitcoin live in production; WooCommerce Payments done on a beta test store.
  • Votes recorded on Cardano mainnet under a registered CIP-10 metadata label (1668).
  • Bitcoin and Cardano managed under one seedphrase, with transactions on both mainnets.
  • All six milestones delivered and documented publicly.

Key achievements

  • CIP-10 metadata label 1668 merged for on-chain dApp ratings (CIPs PR #1012).
  • Seedphrase generated from face data, with passwordless login and signing for both ADA and BTC.
  • BeginPay for WooCommerce with a ~10KB in-browser Cardano transaction builder, replacing the 27MB serialization library.
  • Bitcoin module published in the open source Begin Core.

Key learnings

  • Platform risk is real: Shopify closed external payment integrations, so the payment module moved to WooCommerce, which stays open for merchants.
  • Face data is noisy. A stable seedphrase needs consensus over many captures, not a single scan.
  • One seed across chains needs careful derivation path management and separate indexers per network.

Next steps

  • Keep all four modules maintained in Begin's public releases.
  • Move BeginPay for WooCommerce from the beta test store to official WooCommerce approval and merchant stores.
  • Bring the biometric authorization and payment flows into Begin's next app for everyday payments.

Final thoughts

Thank you to the Project Catalyst community, the reviewers and our partners Fluid and IAMX. This grant let a small team ship voting, biometric access and Bitcoin into one self-custody wallet that people use today, and build a WooCommerce payment module ready for merchants.
